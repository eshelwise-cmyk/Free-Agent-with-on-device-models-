# Agents

This section covers open-source agent applications and harnesses. Each page separates verified capabilities from assumptions and points to the project's official source.

## Included

- [OpenCode](opencode/README.md)
- [JCode](jcode/README.md)

When comparing agents, evaluate the task, tools, model support, permissions, platform support, and maintenance status. Do not choose only by model size or feature count.
