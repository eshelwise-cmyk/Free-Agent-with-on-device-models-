# SuperAGI

SuperAGI is an open-source framework for building, managing, and running autonomous agents. Its project history includes a web interface, toolkits, workflows, SDKs, and agent templates.

## Project status

SuperAGI has a different maintenance history and architecture from newer terminal-first coding agents. Treat it as a separate framework rather than assuming that capabilities or installation steps from OpenCode, JCode, or Prime Agent apply to it.

## Installation

Use the official SuperAGI repository and documentation for the current installation procedure. Do not copy an old command from this guide if the upstream project has changed its dependencies or deployment method.

Official source: https://github.com/TransformerOptimus/SuperAGI
Official documentation: https://superagi.com/docs

## Models

Check the current upstream configuration for supported model providers and API requirements. Prefer documented provider integrations over assuming that any OpenAI-compatible endpoint will work.

## Tools and security

SuperAGI can run tools and autonomous workflows. Review tool configuration, credentials, network access, filesystem access, and execution permissions before enabling autonomous runs.
