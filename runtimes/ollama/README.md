# Ollama

Ollama is a local model runtime commonly used to download and serve local models. Use the current official installation instructions for your operating system.

Typical workflow:

1. Install Ollama.
2. Download a model supported by your hardware.
3. Start the local service if needed.
4. Test the model directly.
5. Connect an agent through the documented API endpoint.

Keep model files and application data on storage with enough free space. Check the exact model's license and hardware needs before use.

Official site: https://ollama.com
Official repository: https://github.com/ollama/ollama
