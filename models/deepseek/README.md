# DeepSeek

DeepSeek publishes multiple model families and releases. Choose the exact model variant rather than treating the family as one model.

For each release, record:

- exact model name
- parameter count
- context window
- quantization options
- coding and reasoning performance
- tool/function calling support
- local runtime compatibility
- license
- official model card
- last verified date

Use the model author's current documentation for the exact release and license terms.

Official source: https://github.com/deepseek-ai
