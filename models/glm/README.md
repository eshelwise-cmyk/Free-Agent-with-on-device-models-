# GLM

GLM is a family of models associated with Zhipu AI / Z.ai. Use the model's current official repository or model card for exact capabilities, license, context, quantization, and supported runtimes.

## Selection checklist

Record the exact model variant, parameter size, quantization, context length, tool-calling support, vision support, license, and local-runtime support. Do not treat all GLM variants as interchangeable.

## Local use

Check whether the exact release is supported by your selected runtime. Compatibility can differ between model versions and quantized formats.

Official model source: https://github.com/THUDM
