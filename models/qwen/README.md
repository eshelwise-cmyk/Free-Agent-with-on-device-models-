# Qwen

Qwen is a model family from Alibaba Cloud's Qwen team. The family contains models with different sizes, modalities, and capabilities.

For each exact release, verify:

- model and parameter size
- context window
- quantization choices
- coding/reasoning ability
- tool calling
- vision or other modalities
- local runtime support
- license
- official model card

Official source: https://github.com/QwenLM
