# Models

Model choice should be based on the task and available hardware, not parameter count alone.

## Model families

- [GLM](glm/README.md)
- [DeepSeek](deepseek/README.md)
- [Qwen](qwen/README.md)
- [Other open-weight models](other-open-models.md)

## Evaluate each model by

- parameter count and memory footprint
- quantization options
- context window
- coding ability
- reasoning ability
- tool/function calling
- vision or multimodal support
- local runtime compatibility
- hardware requirements
- license and usage terms
- speed and latency
- API availability

Model capabilities change. Record a `Last verified` date on specific model pages and prefer the model author's current documentation.
