# Choose a model

Use this order:

1. Define the task.
2. Decide whether local or cloud inference is appropriate.
3. Check hardware or cloud budget.
4. Select a model family and exact release.
5. Select a quantization if running locally.
6. Check context length and tool calling.
7. Test the model on the real task.

## Simple starting points

- Basic chat or lightweight automation: start small.
- Coding and research: use a model with strong instruction following, coding, and tool use.
- Complex reasoning: move to a larger or stronger model only when smaller models fail the task.
- Vision: use a model and runtime that explicitly support the required image inputs.

More parameters are not automatically better for every task. Speed, context, tool support, and reliability can matter more.
