# Skills

Skills are reusable capabilities or procedures that an agent can apply.

Recommended skill groups:

- coding
- research
- browser
- terminal
- file management
- multi-agent orchestration
- MCP/tool use
- model routing
- evaluation
- automation

A skill should state its purpose, inputs, required permissions, expected output, failure modes, and security considerations. Prefer small skills that do one job clearly over giant prompts that try to do everything.
